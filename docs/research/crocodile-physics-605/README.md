# Crocodile Physics 605 — Research Baseline

این پوشه حاصل تحلیل clean-room ساختار Crocodile Physics 605 است و برای طراحی محصول مستقل Aria Lab Physics استفاده می‌شود.

## یافته‌های کلیدی

- ۲۰۹ فایل آزمایش/نمونه شناسایی شد.
- ۲۰۶ ورودی Parts Library و ۲۰۳ کلاس منحصربه‌فرد شناسایی شد.
- ۴٬۹۳۸ تعریف Property و ۵۴۷ اتصال UI به Property استخراج شد.
- معماری نرم‌افزار به دامنه‌های Electronics, Motion, Optics, Waves, Presentation و Flowchart تفکیک شده است.

## سیاست استفاده

در مخزن عمومی فقط داده‌های مشتق‌شده مورد نیاز برای مدل‌سازی و توسعه نگهداری می‌شوند. باینری‌ها، installerها، DLLها، دارایی‌های اصلی و متن کامل Help/راهنما منتشر نمی‌شوند.
