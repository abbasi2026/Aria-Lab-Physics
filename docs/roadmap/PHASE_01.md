# فاز ۱ — هسته داده و موتور پایه

1. تثبیت Schema قطعه و آزمایش.
2. تبدیل داده‌های پژوهشی Crocodile به مدل داخلی Aria.
3. پیاده‌سازی Unit/Quantity system.
4. پیاده‌سازی Property/Binding system.
5. انتخاب ۱۰ آزمایش مرجع برای Mechanics, Circuits, Optics و Waves.
