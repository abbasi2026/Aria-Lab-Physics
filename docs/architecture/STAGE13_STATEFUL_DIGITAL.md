# Stage 13 — Stateful Digital Execution

## هدف

تبدیل بخش مدار دیجیتال از منطق صرفاً ترکیبی به مدارهای ترتیبی قابل لمس و قابل اندازه‌گیری در حالت اجرای دانش‌آموز.

## قطعات اجرایی

- `7474` — فلیپ‌فلاپ D با D/CLK/SET/RESET/Q/Q̅
- `7473` — فلیپ‌فلاپ JK
- `4027` — فلیپ‌فلاپ JK با SET/RESET
- `4043` — لچ RS
- `4017` — شمارنده ده‌دهی یک‌ازده
- `4518` — شمارنده BCD
- `4026` — شمارنده + دیکودر هفت‌قسمتی
- `4511` — دیکودر BCD به هفت‌قسمتی
- `4028` — دیکودر BCD به ده‌دهی

برای ICهایی که در دیتاست Crocodile پورت استخراج‌شده ندارند، Stage 13 از Virtual Ports مشخص و ثابت استفاده می‌کند تا اتصال روی برد واقعی باشد و به Solver منطقی Net-based متصل شود.

## رفتار علمی

- D Flip-Flop فقط روی لبه بالارونده CLK از D نمونه‌برداری می‌کند.
- JK در J=K=1 در هر لبه بالارونده Toggle می‌شود.
- RS در S=R=0 حالت قبلی را حفظ می‌کند و S=R=1 را به‌عنوان حالت نامعتبر گزارش می‌دهد.
- 4017 خروجی one-hot و Carry تولید می‌کند.
- 4518 مقدار 0..9 را به BCD چهار بیتی تبدیل می‌کند.
- 4026 شمارش را مستقیماً به خطوط a..g تبدیل می‌کند.
- 4511 BCD را به الگوی هفت‌قسمتی تبدیل می‌کند.
- 4028 BCD را به خروجی one-hot Q0..Q9 تبدیل می‌کند.

## حفظ State در UI

Runtime دیجیتال حافظه `{q,count,prevClock}` را در Snapshot نگه می‌دارد. هنگام تغییر ورودی لمسی، Runtime می‌تواند Property همان Part را بدون بازسازی کامل تغییر دهد. اگر Editor ناچار به بازسازی Runtime شود، Memory صریحاً Restore می‌شود تا Q/Count از بین نرود. `Reset` یک آزمایش Runtime جدید می‌سازد و بنابراین State را عمداً صفر می‌کند.

## نمایش روی برد

Execution Frame وضعیت Q، Count و Digit را به UI منتقل می‌کند. قطعات حالت‌دار کلاس‌های دیداری اختصاصی دارند و Readout زنده از خروجی Solver نمایش داده می‌شود؛ نمایشگر هفت‌قسمتی نیز `data-digit` واقعی دریافت می‌کند.

## آزمایش‌های اجرایی

1. فلیپ‌فلاپ D و حافظه یک‌بیتی
2. فلیپ‌فلاپ JK در حالت Toggle
3. لچ RS؛ تنظیم، حفظ و بازنشانی
4. شمارنده ده‌دهی 4017
5. شمارنده BCD + 4511 + نمایشگر هفت‌قسمتی
6. دیکودر BCD به ده‌دهی 4028

## محدودیت‌های Stage 13

- Timing propagation delay، metastability و setup/hold time در این Stage مدل نمی‌شوند.
- رفتار تغذیه VCC/GND و محدودیت‌های الکتریکی واقعی ICهای TTL/CMOS به مدل منطقی ایده‌آل تقلیل داده شده‌اند.
- Enable/Latch-Enable/Clock-Inhibitهای ویژه بعضی ICها هنوز مدل کامل دیتاشیت نیستند مگر آنجا که در Virtual Port قرارداد Stage 13 آمده باشد.
- این محدودیت‌ها عمداً شفاف‌اند؛ UI برای قابلیت مدل‌نشده رفتار جعلی تولید نمی‌کند.
