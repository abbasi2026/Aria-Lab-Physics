# Stage 10 — Executable Crocodile Optics

Stage 10 makes the full 21-part Crocodile optics palette executable at the geometry/runtime level.

Supported behaviors include ray bundles, thin lenses, plane/spherical/parabolic mirrors, transparent polygons, semicircular refraction, opaque absorbers, adjustable slits, screen hits, an eye lens/retina model, and optical-space containers.

Five executable reference experiments are included: concave-mirror focus, prism refraction/internal reflection, transparent block, shadow formation, and adjustable slit.

All visible part names remain Persian. Geometry is clean-room and solver-driven; no Crocodile binary assets or source code are reused.
